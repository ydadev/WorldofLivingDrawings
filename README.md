# World of Living Drawings

Веб-платформа, в которой бумажные и цифровые раскраски становятся объёмными обитателями общего интерактивного мира.

Первый релиз: подводный мир с фиксированной камерой, рыбами, кормлением и подводной лодкой. Рисовать можно на бумаге или в браузере телефона, планшета и компьютера.

Инфраструктура подготовлена; идёт этап технических проверок перед реализацией приложения. Проверочная HTTP-страница пока не является приложением.
