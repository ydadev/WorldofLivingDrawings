# Проверка бумажного пути Capture

`RISK-03` не может получить статус DONE только по синтетическим изображениям. Нужны реальные распечатки обоих [листов](../prototypes/fish-assets/generated/) на A4 и фотографии с телефонов. Маркеры версии WLD1 — четыре QR-кода, каждый содержит вид, версию шаблона, 80-битный префикс SHA-256 раскладки и позицию угла. Формат, размер и координаты — в `prototypes/fish-assets/paper-format.json`. Прототип использует [node-qrcode 1.5.4, MIT](https://github.com/soldair/node-qrcode/blob/master/package.json) для генерации и [jsQR 1.4.0, Apache-2.0](https://github.com/cozmo/jsQR/blob/master/package.json) для декодирования. Пригодность этого формата на реальной бумаге и возможность дальнейшего WASM-варианта ещё требуют измерений; это технический кандидат, а не подтверждённая приёмка.

Для первичной серии распечатать оба листа и сделать фотографии с полностью видимыми четырьмя маркерами: карандаши и фломастеры, разные телефоны, дневной и искусственный свет, разные перспективы и небольшая размытость. Валидным считается снимок, на котором человек может прочитать все маркеры и понять вид рыбы. Сильно обрезанные/неверные листы и другие изображения составляют отдельный отрицательный набор. Не подбирать порог или менять алгоритм на итоговом наборе после оценки; для доработки использовать отдельную тренировочную серию.

Для количественной приёмки нужны не менее 100 заранее размеченных валидных фото **каждого** шаблона. Цель — ≥95% правильного автоматического распознавания каждого вида; на отдельном отрицательном наборе — 0 принятых неверных идентификаций. Время обработки, причины отказа и визуальное качество совмещения оцениваются отдельно. Реальные фото, манифест и подробный отчёт хранятся только в игнорируемой `.local/`; их не добавляют в Git и не отправляют на сервер приложения.

Манифест `.local/capture-dataset/manifest.json`:

```json
{
  "valid": [
    { "file": "coral/photo-001.jpg", "templateId": "coral" },
    { "file": "stream/photo-001.png", "templateId": "stream" }
  ],
  "negative": [
    { "file": "negative/cropped-marker.jpg" }
  ]
}
```

После `npm run build` в `prototypes/wasm-webgl` запустить из корня `node tools/evaluate-capture.mjs`. Скрипт читает только приватную папку, отправляет фото локальному браузеру, пишет только агрегированные итоги в `.local/capture-evaluation.json` и возвращает PASS лишь при выполнении всех порогов. Пока реального набора нет, этот запуск имеет статус NOT_RUN. Синтетическая проверка `npm run test:capture` подтверждает работу формата и коррекции, но не измеряет указанные проценты на бумаге.
