# Документы проекта

Актуальные документы для первого релиза:

1. [ТЗ 1.1 — подводный мир](TZ-1.1.md): согласованный объём, одна фиксированная камера, бумажная и браузерная раскраска на обе стороны рыб, редактор для телефона/планшета/ПК (§3.4), кормление, лодка и технические требования.
2. [Эксплуатационные правила](operating-rules.md): роли, повторные команды, сеть, лимиты, локальные цифровые черновики (§6.1), сохранение, удаление и backup.

Они имеют приоритет над противоречащими требованиями исходного ТЗ для первого релиза. Остальные совместимые архитектурные требования исходника сохраняются. Численные настройки являются базовыми значениями для реализации, а не измеренными возможностями готовой системы.

История:

- [ТЗ 1.0](TZ-1.0-original.md) — исходник без изменений.
- [Проверка ТЗ 1.0](TZ-review.md) — исходный аудит до согласования решений.
- [Первый проект дополнения](TZ-1.1-proposal.md) — исторический черновик; не использовать как текущую спецификацию.

Порядок работы: [STATUS](STATUS.md), [TASKS](TASKS.md), [WORKLOG](WORKLOG.md), [DEVELOPMENT](DEVELOPMENT.md), [DECISIONS](DECISIONS.md). Каркас: [ARCHITECTURE](ARCHITECTURE.md), [SERVER-DEVELOPMENT](SERVER-DEVELOPMENT.md). Инфраструктура: [INFRASTRUCTURE](INFRASTRUCTURE.md), [RUNBOOK](RUNBOOK.md). Короткое задание для продолжения: [CONTINUE](CONTINUE.md).

Технические проверки завершены в части, не требующей реальных фото и TV. Начат каркас приложения; фактическая готовность отражена в статусе и журнале.
