# Текст для продолжения разработки

Продолжай World of Living Drawings по AGENTS.md. Прочитай docs/STATUS.md, docs/TASKS.md и последние записи docs/WORKLOG.md. Выполни следующую готовую задачу по зависимостям и критериям приёмки, проверь результат и обнови статусы и журнал. Не расширяй объём стихийно. В Git используй только ydadev и служебную noreply-почту; сообщение коммита — только дата YYYY-MM-DD. Секреты и личные данные не публикуй. Резервные копии храни в `.local/backups/` проекта и не добавляй в Git.

Если ближайшая задача заблокирована, зафиксируй причину и выполни следующую независимую READY-задачу. Не отмечай серверное действие выполненным только потому, что для него подготовлен скрипт.
