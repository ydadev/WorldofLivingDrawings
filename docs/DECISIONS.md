### ADR-018 — хранение Paint Texture

Текущий `normalized_png` в `upload_intents` — ограниченный по времени карантин, а не место постоянного хранения. Постоянные детские текстуры хранятся на уже подготовленном томе `/var/lib/ldw/blobs`. ID — полные 64 символа SHA-256 проверенного нормализованного PNG. Файл находится только в вычисленном сервером пути `sha256/<первые два символа>/<ID>.png`; пользовательский путь не принимается. Повторная запись того же содержимого не заменяет файл. Права на выдачу определяются текущей ссылкой Entity/сцены и grant, не знанием ID. Рассмотренные варианты: хранить всё в PostgreSQL BYTEA (простая транзакция, но рост и нагрузка на БД) либо отдельные изменяемые файлы по UUID (сложнее восстановление и дедупликация). Выбраны неизменяемые файлы с учётом ссылок в БД для исходной конфигурации 2 vCPU/8 ГБ и готового persistent volume.

Для публикации сервер записывает файл во временный путь на том же томе, проверяет хеш, синхронизирует файл и каталог, атомарно размещает конечный файл без перезаписи существующего, затем фиксирует ссылку, квоты, результат intent и публикацию одной транзакцией БД. При ошибке до commit файл может остаться без ссылки, но Entity на отсутствующий файл не подтверждается. GC удаляет только доказанно невостребованный файл после 24 часов и не работает во время согласованного backup. Сцена учитывает размер каждого отличного blob один раз вместе с корзиной и резервированием; лимит — 256 МиБ, физический лимит установки — 20 ГиБ. Совпадающие файлы разных сцен не обходят квоту ни одной сцены. Необработанные фотографии и метаданные в blob не попадают.

Обновлённый `infra/backup-local.sh` использует экспортируемый снимок PostgreSQL и общую с финализацией/GC блокировку до окончания архивации неизменяемых файлов. Скрипт и восстановление тестового дампа прошли Ubuntu/PostgreSQL CI, но новая версия ещё не установлена на runtime-сервере. До пилота нужны manifest, развёртывание и проверка восстановления: открытие сцены, авторизованная выдача PNG и продолжение симуляции. По решению пользователя копии пока остаются в `.local/backups/` проекта, исключённой из Git; внешнее зашифрованное хранилище — отдельный незакрытый этап INFRA-05.
